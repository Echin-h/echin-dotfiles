# Herdr 代码阅读工作区

在项目目录运行 `mcode .`；审阅使用 `mreview`。
`mcode path/to/file.tsx` 可直接打开文件，也支持 Neovim 的 `+行号` 参数。

## mreview：一个审阅工作区

| 命令 | 初始范围 |
| --- | --- |
| `mreview` | 默认主分支共同祖先 → HEAD |
| `mreview feature/name` | 默认主分支共同祖先 → 目标分支 |
| `mreview HASH` / `mreview --commit HASH` | 第一父提交 → 该提交，支持首次提交 |
| `mreview A B` / `mreview A..B` | A → B 的完整快照 |
| `mreview A...B` | A、B 的共同祖先 → B |
| `mreview --history [分支或范围]` | 提交选择列表，默认选中最新提交 |

- **审阅范围**：顶部固定「整体改动 / 提交历史」。选择提交直接更新当前 Diff，不叠加审阅标签；切回整体改动恢复原比较范围、文件和阅读位置。直接进入单次提交时，「整体改动」指启动时指定的比较范围。
- **提交历史**：先加载 20 条，底部「加载更多提交」继续读取；单击 / 回车选择，Esc / q 关闭列表。普通比较只列出对应范围中的提交；显式 `--history` 使用指定分支或范围。
- **文件导航**：左栏固定「改动文件 / 完整目录」。完整目录来自 Git 版本树，标记本次改动并定位当前文件。单击文件在右侧预览；回车 / 双击打开完整阅读。
- **版本**：代码栏显示旧版 / 新版及 SHA。点击对应代码后，目录、定义、引用、大纲使用该侧版本；预览也显示 SHA，历史结果不会跳到当前工作区代码。
- **代码上下文**：定义 `gd` / Ctrl+左键，引用 `gr` / Ctrl+右键，大纲 `Space r o`，文档 `K`。定义、引用、大纲共用右侧结果与代码预览。Go、TS/JS/React 支持历史语言服务，其他语言或缺少依赖时会提示。
- **预览与阅读**：单击 / 上下选择只更新预览；「打开阅读」/ 回车进入完整只读代码。Esc / q /「关闭预览」收起右侧区域。引用列表按 `t` 查看相邻文件。
- **返回规则**：「后退」/ `mm` / Command+[ 逐层返回；「前进」/ Command+] 前进；完整阅读页的「返回审阅」/ `gR` 直接回到原 Diff、光标与滚动位置。
- **更多操作**：通过 `Space r m` 打开复制位置、切换 Worktree、文件搜索、全文搜索菜单。`Space r h` 提交历史、`Space r a` 整体改动、`Space r f` 改动文件、`Space r e` 完整目录、`Space r m` 更多。
- **退出审阅**：顶部按钮结束 `mreview`；从 `mcode` 打开的审阅关闭后返回编辑器。F1 显示当前审阅指南。

新增 / 修改行以绿色背景标出，修改字符使用更亮绿色，删除使用红色；统计显示 `+新增 -删除`。左右 Diff 滚轮同步，按对应代码对齐。审阅不自动弹出 hover。

默认基准优先使用 `origin/HEAD`，可通过 `MATE_REVIEW_BASE` 指定；`MATE_REVIEW_NVIM` 可指定 Neovim 程序。缺失的 hash 会查询已配置 remote（优先 origin）的分支、标签、PR 引用和历史，必要时补全浅克隆。短 hash 须唯一，建议使用完整 hash。CNB 的临时凭据回退只用于本次请求，不修改全局 Git 配置或钥匙串。

审阅不切换分支，不修改工作文件；历史代码只读。`:DiffviewClose` 关闭视图，`:qa` 退出编辑器。

## mcode：普通代码阅读

- 目录树：单击目录展开/折叠，单击文件打开。状态图标已恢复原样。
- 顶部文件标签：空白、未命名且未修改的启动页自动隐藏；输入内容后恢复显示。鼠标放在标签栏上，双指左右滑动浏览隐藏标签；当前文件、光标和代码视图保持不变。点击标签才切换文件。
- 函数跳转：`gd` / Ctrl+左键；也可以点击函数，再点顶部定义。
- Worktree：点击顶部 Worktree，或 `Space g w`；原生列表支持上下键、j/k、Ctrl-j/k 选择，回车或单击切换；Esc / q 或点击「关闭」退出列表。编辑内容保留，普通文件自动保存；已打开的 worktree 直接返回原页。
- 阅读返回/前进：顶部 后退 / 前进，恢复上一处文件、光标和阅读位置（包括打开文件和函数跳转）。
- Command + `[` / Command + `【` 与当前页面的 `mm` 完全一致（历史定义页返回审阅）。普通代码 `mm` / Ctrl-o 返回 Vim 跳转历史，Ctrl-i 前进；插入时 `jj` 退出插入。H 到行首，L 到行尾。
- 定义查找失败会提示未找到、语言服务不可用或查询超时；失败不会增加返回记录。
- 引用：顶部引用；结果列表可单击打开。按 Esc / q，或点击列表顶部「关闭结果」收起列表并回到代码。
- CSS/文档：鼠标停留 450ms；或点顶部文档 / 按 K。
- Git diff：顶部 Git；`:DiffviewClose` 退出 diff。
- 文件查找：Space Space；全文搜索：Space /；点击搜索弹窗的「关闭」或外部关闭，原有 Esc、恢复搜索、回车打开保留。目录树：Space e。
- 右键菜单：定义、引用、说明、复制位置、Git diff、阅读指南。
- 选中代码后：右键 Copy selection；复制路径行号用 Space y p。
- F1 或顶部 ?：打开操作说明。
- 点击顶部工具栏的「退出」关闭 `mcode`；有未保存修改时会询问是否保存。也可以 Esc 后 `:qa` 回车退出。`:w` 保存当前文件。

普通可编辑文件自动保存：停止输入约 800ms、退出插入、切换文件或失去焦点时写入。未命名文件、只读文件和历史快照不自动保存。自动格式化保持关闭；写入失败会提示并保留编辑内容。

诊断文字默认不显示在代码行尾或额外行中；函数跳转、引用查找和诊断数据仍可用。需要时用 `:lua vim.diagnostic.open_float()` 查看当前行的诊断说明。

Go 使用已有 gopls；TS/JS/React 使用 vtsls；Tailwind 使用官方 language server。
Tailwind v4 需要项目安装依赖，并有导入 Tailwind 的 CSS 入口；多项目可按官方设置指定入口。
工具安装在 ~/.local/share/mate-code-tools，插件版本记录在 lazy-lock.json。
`:Lazy` 管理插件；`:Mason` 管理附加语言工具；`:checkhealth` 查看环境。

字体为 JetBrainsMono Nerd Font；旧配置由仓库安装脚本备份到 `~/.local/state/echin-dotfiles/backups/`。
Herdr 右键若打开其自身菜单，可将阅读分屏的 right-click 路由设为 pane。
鼠标停留依赖终端转发 mouse-move；若未转发，点击类名后用 Info 始终可用。
本配置只复制选区/文件位置到剪贴板，不会自动给 agent 发消息。

Markdown 行内反引号代码保留文字颜色，不显示单独的彩色底。

文档中的 Markdown 文件链接、反引号路径和 `../` 相对路径可单击打开，路径相对当前文档目录解析。也可将光标放在路径上点定义 / 按 gd / Ctrl+左键；普通函数仍使用定义跳转。支持 `#L数字` / `:行号`，不存在的文件只提示，不会创建空文件。历史 review 读取对应提交的只读文件，后退 / mm / Command+[ 返回。
Ghostty 默认 Command+[ 用于切换分屏；已覆盖为向 Neovim 转发返回键（兼容 Command+【 和物理左方括号）。修改终端配置后按 Command+Shift+, 重载 Ghostty，无需关闭会话。

Command + `]` / Command + `】` 前进，与 Command + `[` / Command + `【` 返回配对。普通文件使用原生 Ctrl-i 跳转历史；历史快照和 review 使用顶部前进 对应的阅读历史。Ghostty 配置新增右括号转发后，按 Command+Shift+, 重载终端配置。
